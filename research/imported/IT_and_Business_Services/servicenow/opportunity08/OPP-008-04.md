# 1. Research Question

OPP-008-03 established that basic ServiceNow healthcare coordination is credible, while a broader hospital-wide decision-synthesis capability remained unproven.

This checkpoint asks:

> **When several patient-flow constraints interact simultaneously, can the strongest reasonable ServiceNow architecture adequately determine and coordinate the next operational intervention, or does a residual decision-synthesis problem remain?**

The test deliberately compares:

```text
A — BASIC SERVICENOW WORKFLOW

B — SERVICENOW + CONFIGURATION / AI

C — SERVICENOW + EXTERNAL OPTIMIZATION

D — SPECIALIZED DECISION-SYNTHESIS LAYER
```

The objective is to falsify D wherever A, B, or C is sufficient.

---

# 2. Evidence Discipline

This is a controlled analytical reconstruction.

It is **not** a claim that the following exact patient state occurred in a named hospital.

The scenario is assembled from independently documented hospital-flow constraints and decision patterns.

## DIRECT / VERIFIED EVIDENCE

Used to establish that the individual constraints and decision patterns are real.

## CONTROLLED SCENARIO

Used to test whether a decision architecture can reconcile those constraints.

## INFERENCE

Used to construct relationships between documented constraints.

## HYPOTHESIS

Used for any claim about a residual technology gap.

# 5. Decision Objective

The operational question is:

> **Which intervention should the command centre prioritize now to improve patient flow while respecting available capacity and operational constraints?**

Potential actions include:

```text
A1 — PRIORITIZE A DISCHARGE-BLOCKING LAB TASK

A2 — REALLOCATE AVAILABLE STAFF

A3 — EXPEDITE ANOTHER DISCHARGE

A4 — CHANGE BED ASSIGNMENT / PLACEMENT

A5 — ESCALATE A BOTTLENECK TO ANOTHER DEPARTMENT

A6 — PREPARE FOR THE EXPECTED URGENT ADMISSION

A7 — COMBINE MULTIPLE ACTIONS
```

### Classification

These are **CONTROLLED SCENARIO OPTIONS**, not documented actions from one real event.

---

# 6. Why This Is a Harder Decision

The decision is no longer:

```text
TASK OVERDUE
 ↓
ROUTE TASK
```

It is:

```text
MULTIPLE BOTTLENECKS
        +
LIMITED CAPACITY
        +
TIME PRESSURE
        +
MULTIPLE PATIENTS
        +
MULTIPLE POSSIBLE ACTIONS
        ↓
WHICH ACTION FIRST?
```

This is the decision boundary under investigation.
